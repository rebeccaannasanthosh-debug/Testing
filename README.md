# Setup Process

This document outlines the steps taken to set up the development environment and connect it to GitHub.

## Tools Installed

- **Cursor** — IDE
- **Claude Code** — extension
- **Codex** — extension

## Setup Steps

The steps mentioned via email were all completed, though not in the exact sequence described. Here is the order in which they were done:

1. **Installed Cursor IDE** — First step completed.
2. **Created a GitHub account and public repository** — Account and repo were set up quickly.
3. **Added Claude Code and Codex as extensions in Cursor** — Both extensions were installed in the IDE.
4. **Logged into Claude Code and Codex** — Required downloading Claude Code and Codex to the desktop first (this took some time due to slow internet).

## Challenges & Solutions

### Downloading the repository file

Creating the public GitHub repository was quick, but downloading the file took longer. After some research, I realized I had missed the **file creation step within GitHub**. Once that was done, I was able to download the file and open it in Cursor without issue.

### Pushing to GitHub

The second roadblock came when trying to push this file to GitHub. I had to backtrack, install **GitHub Desktop**, and connect it to Cursor to complete the task.

## Outcome

This README documents the full setup process from installation through resolving GitHub sync issues.
